Privacy Policy

Effective date: 15 November 2026

Who uses Sanad

Sanad is a private tool used only by its owner. It is not offered to the public.

What data Sanad accesses

With the owner's permission, Sanad accesses files in the owner's own Google Drive, Google Docs and Google Sheets. It does not access Gmail or any other Google service.

How the data is used

The data is used only to help the owner read and organize their own files. To provide these features, file content may be processed by a third-party AI model provider acting on the owner's behalf. The data is not sold, not shared for advertising, and not used for any purpose other than serving the owner.

Storage and security

Access tokens are stored encrypted on the owner's private server. File content is not stored by Sanad beyond what is needed to complete a request.

Google API Services

Sanad's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from myaccount.google.com/permissions.
